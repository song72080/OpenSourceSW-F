# FITLOG

운동 목록을 확인하고 운동한 시간과 내용을 기록할 수 있는 간단한 웹 프로젝트입니다.

## 주요 기능
- 기본 운동 목록 확인
- 운동 이름과 운동 시간 입력
- 운동 기록 삭제
- 기록한 날짜 자동 표시
- 브라우저 LocalStorage에 기록 저장

## 사용 기술
- HTML
- CSS
- JavaScript

## 실행 방법
1. `index.html` 파일을 브라우저에서 엽니다.
2. 운동 이름과 시간을 입력하고 기록 추가 버튼을 누릅니다.
3. 등록된 기록은 같은 브라우저에 저장됩니다.
